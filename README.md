# Classic Hotel Ijebu-Ode — Website Concept

Live demo: https://classic-hotel-ijebu-ode.higgsfield.app

This repository contains source files for an independent website concept for Classic Hotel in Ijebu-Ode, Ogun State. It is not the hotel's official or approved website.

## Important notes
- The room, pool, dining, and hero images are illustrative stock photos, not verified photos of the hotel.
- Hotel facilities and address are based on public listings and should be confirmed directly with the hotel.
- Confirm room types, prices, and availability with the hotel before publishing a production version.

## Source
The main page component is in `app/src/routes/index.tsx` and the site's styling is in `app/src/styles.css`. These files come from the Higgsfield website project scaffold; the full scaffold and workspace packages are not mirrored here yet.
